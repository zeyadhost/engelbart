# Contributing

Engelbart is a compile-time USB device compiler for embedded C++. The first supported target is Raspberry Pi Pico WH / RP2040 with Pico SDK and TinyUSB.

Keep contributions focused on the current scope: HID mouse, boot keyboard, composite mouse + keyboard, deterministic descriptor bytes, validation, inspection, tests, and Pico smoke integration.

## Build and Test

Run the host build and tests before opening a PR:

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

When touching Pico/TinyUSB integration, also build the smoke firmware if the Pico SDK toolchain is available:

```sh
cmake -S examples/pico_tinyusb_smoke -B build-pico-smoke -DPICO_BOARD=pico_w
cmake --build build-pico-smoke
```

## Scope

Do not add CLI, GUI, dashboard, Studio, Inspector, runtime descriptor interpreter, runtime descriptor reconfiguration, CDC, MIDI, gamepad, vendor class, or multi-board support without a prior RFC or ADR.

Do not frame examples around spoofing, BadUSB, anti-cheat bypass, or real-product impersonation. Use non-impersonating test identities such as the pid.codes-style test VID `0x1209`.

## Design Changes

Architecture changes should update the relevant docs:

- `docs/principles.md`
- `docs/non-goals.md`
- `docs/adr/`
- `docs/rfc/`
- `docs/testing-strategy.md`
- `docs/versioning.md`

Descriptor byte changes should update golden tests deliberately and explain why the generated bytes changed.
