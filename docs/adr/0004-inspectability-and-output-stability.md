# ADR 0004: Inspectability and Output Stability

## Status

Accepted for Phase 1 architecture.

## Context

USB debugging often fails because developers cannot easily see the exact descriptors, endpoint layout, report descriptors, and integration code that the host observes.

Engelbart's abstractions must make this easier, not harder.

## Decision

Generated output must be inspectable and deterministic.

Users must be able to see generated USB descriptors, HID report descriptors, endpoint allocation, interface numbering, and TinyUSB glue.

Descriptor byte changes should be treated seriously because host compatibility may depend on them.

## Inspectability requirements

Engelbart should expose inspection artifacts for:

- USB device descriptor bytes
- Configuration descriptor bytes
- HID report descriptor bytes
- Endpoint allocation
- Interface numbering
- String descriptor policy
- TinyUSB descriptor callbacks and glue

The exact format is not decided in this ADR. Acceptable formats may include generated headers, build artifacts, text dumps, JSON, or test fixtures.

ADR 0013 defines the year-one minimum inspection baseline. ADR 0008 and ADR 0013 defer stable JSON unless a later ADR explicitly stabilizes it.

## Output stability

Generated descriptor output should be stable for a given input, target, and Engelbart version.

Changes to generated bytes should be:

- intentional
- tested
- reviewable
- documented in release notes
- considered compatibility-relevant

## Rationale

Host operating systems and USB stacks may depend on descriptor details even when the USB specification allows variation. Byte-exact output lets users review diffs, reproduce bugs, and understand compatibility changes.

Inspectability also keeps TinyUSB as an implementation layer instead of a hidden source of behavior.

## Consequences

- Golden descriptor tests are required from the beginning.
- Generated artifacts should be easy to diff.
- Descriptor changes should not be treated as harmless formatting churn.
- Escape hatches must make their generated bytes visible.
